# CodeAlpha Data Visualization Project

## Project Overview
This project presents a visual analysis of 1000 books using Python.
The goal is to understand book prices, ratings, and availability through charts and a dashboard.

## Dataset
- Total Records: 1000 Books
- Columns: Book Name, Price, Rating, Availability

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations
1. Books by Rating
2. Book Price Distribution
3. Average Price by Rating
4. Book Availability

## Key Findings
- Total Books: 1000
- Average Price: £35.07
- Highest Price: £59.99
- Lowest Price: £10.00
- All 1000 books are In stock.

## Project Files
- all_books_data.csv

- books_dashboard.png

## Conclusion
This dashboard makes it easier to understand book prices, ratings, and availability through visual representations.
